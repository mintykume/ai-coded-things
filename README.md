# ai-coded-things
Random things I vibe coded with AI that I find useful or fun.

| Thing | What it is | Try it |
|---|---|---|
| [tetris-terminal-game](tetris-terminal-game/) | Tetris in the terminal, in Python. No graphics, no ads | `python3 tetris.py` |
| [vinyl-label-studio](vinyl-label-studio/) | Put any picture on a spinning record and save the drop as a video for edits | [open](https://mintykume.github.io/ai-coded-things/vinyl-label-studio/) |
| [thirty-sits](thirty-sits/) | A 30-day meditation challenge tracker with calm-before and calm-after ratings | [open](https://mintykume.github.io/ai-coded-things/thirty-sits/) |

The web ones are single HTML files: no install, no account. Download a folder and open `index.html`, or use the links above.
